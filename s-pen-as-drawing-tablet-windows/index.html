Windows guide

Use your S Pen as a drawing tablet on Windows.

PenCast sends the pen from your Galaxy to your PC as native Windows pen input — pressure included, even in the free tier. Not the picture, just the pen. No ads.

Download for Windows (.exe)Coming soon to Google Play

The Android app is on its way to Google Play; the desktop app pairs with it. Email me for a heads-up.

What you need

  • A Samsung Galaxy with an S Pen (see the Galaxy Tab guide), Android 7.0 or newer.
  • A 64-bit Windows 10 (1809 or newer) or Windows 11 PC, on the same WiFi network — or a USB cable.
  • The free PenCast desktop app on the PC and the PenCast Android app on the Galaxy (coming to Google Play).

Set it up in five steps

  1. Download the installer. Get PenCast-Setup.exe and run it.
  2. If SmartScreen warns you, choose More info, then Run anyway (the installer isn't code-signed yet). If Windows asks about network access, allow it on private networks so your Galaxy can find the PC over WiFi.
  3. Install the Android app on your Galaxy (coming soon to Google Play).
  4. Connect. Scan the QR code shown on the PC, or let auto-discovery find it. Prefer a cable? Turn on USB debugging and pick USB.
  5. Draw. Open a pen-aware app and draw on the Galaxy. If pressure doesn't register, set the app to Windows pen input (Windows Ink) in its tablet settings.

Honest limits

  • Your tablet won't show your canvas. PenCast is a pen tablet, not a screen mirror: you look at your computer and draw on your Galaxy.
  • WiFi mode isn't encrypted yet. Use USB, Bluetooth (Pro) or a network you trust.
  • Installers aren't signed yet. The Windows installer isn't code-signed, so SmartScreen asks for one extra click (step 2).
  • Apps differ. Compatibility depends on your drawing app and its pen settings. I haven't published a tested-apps list yet — try the free version first and tell me what works.
  • The Android app is coming to Google Play. The desktop app pairs with it; until it's live there's nothing to pair with.

When something else fits better

On Windows you have strong alternatives. If you want the Windows desktop on your tablet screen — a second monitor you can draw on — SuperDisplay and Samsung Second Screen do that; PenCast does not. If you want a pen tablet with no screen mirroring, no ads and a pay-once Pro, PenCast is built for that.

Questions

Do I need to install anything on the PC?

Yes — the free PenCast desktop installer. It receives pen data from your Galaxy and creates a virtual pen device in Windows, so apps see pen input with pressure.

Will my PC show the canvas on the tablet?

No. PenCast sends the pen, not the picture. If you want the Windows desktop on the tablet, use a screen-mirroring app such as SuperDisplay or Samsung Second Screen.

Pressure isn't working in my app. What should I check?

Make sure the app is set to use Windows pen input (Windows Ink) rather than an older driver mode — many drawing apps have a tablet-input setting for this. Menu names vary by app and version, so check the app's own documentation.

Why does SmartScreen warn me?

The Windows installer isn't code-signed yet. Choose More info, then Run anyway. Signing is on the to-do list.

Which Windows versions are supported?

The receiver is built for 64-bit Windows 10 (version 1809 or newer) and Windows 11, because it relies on Windows' synthetic pen API. I haven't tested every build.
